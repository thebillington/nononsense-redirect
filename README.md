# No Nonsense redirect

`nononsense.thebillington.co.uk` was the original address of the No Nonsense
revision site. The site now lives at
[nononsenserevision.uk](https://nononsenserevision.uk/).

This repository exists only to keep old links working. It is a GitHub Pages
site on the old hostname, and it sends every path to the same path on the new
domain. Replace it with a proper Cloudflare 301 redirect when that is set up.

There is no content here, and nothing in this repository is indexed.
